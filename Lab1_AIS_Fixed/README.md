# Практическая работа 1. Магазин гномиков

Учебная многослойная информационная система на C# и .NET Framework 4.7.2.

## Структура решения

- Model — сущность Product и класс Logic с операциями над товарами.
- Lab1_AIS — консольное представление.
- WindowsFormsApp1 — представление Windows Forms.

Оба представления ссылаются только на Model. Модель не использует элементы интерфейса.
В коде оставлены обычные классы, списки, циклы и условия, а также комментарии summary.
Готовые строки отчётов формируются в Logic ради простоты учебного примера.

## Как запустить

1. Откройте Lab1_AIS.sln в Visual Studio 2022.
2. Для сборки нужны средства разработки классических приложений .NET и targeting pack .NET Framework 4.7.2.
3. В обозревателе решений нажмите правой кнопкой на Lab1_AIS или WindowsFormsApp1 и выберите «Назначить запускаемым проектом».
4. Запустите приложение.

Консоль начинает с трёх примеров товаров. Форма начинает с пустого списка.
У каждого приложения свой список в памяти. Данные между запусками не сохраняются.

## Работа с формой

Для добавления заполните поля и нажмите «Добавить».
Для изменения выберите товар в списке: его данные появятся в полях.
Измените нужные поля, в том числе название, и нажмите «Изменить».
«Удалить», «Купить» и «Скидка» работают с выбранным товаром.
После операции поля очищаются; для следующей операции снова выберите товар.
«Показать все» показывает полный список, «Группировка» — список по типам.

## Правила и бизнес-функции

Название и продавец не могут быть пустыми. Названия уникальны без учёта регистра
и пробелов по краям. Цена и остаток не могут быть отрицательными.
Тип выбирается из трёх вариантов.

- Покупка уменьшает остаток на одну единицу. При нулевом остатке покупка запрещена.
  Товар остаётся в каталоге, чтобы его можно было пополнить через изменение.
- Скидка от 1 до 99% уменьшает текущую цену с округлением до двух знаков.
  Повторная скидка применяется к уже изменённой цене.
- Дополнительная функция — группировка по типу.

В обоих представлениях доступны добавление, чтение, изменение и удаление.
